# 使用说明

## 推荐的第一次体验

首次使用按“设备配置 → 校准 → 遥操作验证 → 采集 → 回放 → 训练 → 推理”的顺序进行。本地模式不要求登录账号。

### 1. 建立设备组

进入设备配置，新建设备组，扫描并选择 SO-101 主臂和从臂串口。添加所需相机，为相机指定腕部、第三视角等角色，并确认分辨率和帧率后保存。

### 2. 校准和遥操作

按界面步骤调用 LeRobot 官方校准。保证机械臂周围有活动空间，按提示移动关节、完成校准，再验证主从遥操作。不要用其他机械臂的校准文件代替当前设备的校准结果。

### 3. 录制数据

创建采集任务，选择已就绪的设备组，填写任务描述、数据集名称、Episode 数量及每轮时长。开始后观察相机预览与状态，演示任务动作；按需提前结束本轮或重新录制。完成任务后在数据集管理页检查结果。

### 4. 检查数据

打开数据集回放，核对画面、动作和 Episode 完整性，使用界面提供的标注功能整理数据。也可导入本地数据集；当前训练链路要求符合 LeRobot v3.0 数据集结构，不能仅导入一个 MP4 文件代替数据集。

### 5. 训练模型

在模型训练中新建任务，选择数据集和 Episode，选择 ACT 或 SmolVLA，设置训练步数、batch size、日志与保存频率后开始。初次建议用少量数据和较少步数验证流程，再进行正式训练。

查看训练日志中的步数和 loss 判断是否推进。红色文字可能是警告；出现异常栈或任务失败时，保留日志。中断任务前检查是否已有 checkpoint，不能假设尚未保存的训练进度可恢复。

### 6. 运行与验证

训练完成后进入模型库，或导入兼容的本地模型，选择对应设备组并检查输入相机角色、关节及配置一致性，再运行推理。首次推理应保持设备工作区域无人、可随时停止，并观察真实执行效果。训练 loss 下降不等于实际任务一定成功。

## 云端模式

软件包含云端连接和任务相关界面，但本仓库仅发布桌面客户端，不提供公共服务端、测试账号或 API 密钥。没有服务端时请使用本地模式。

## 问题反馈

在 [Issues](https://github.com/Allentide/Tide-workstation/issues) 提交 macOS 版本、芯片、应用版本、设备型号、复现步骤和错误片段。默认训练日志位于 `~/Documents/models/<任务 ID>/training.log`。
